Cada projeto fica em sua própria pasta, numerada na ordem em que foi feito, com seu próprio README detalhando objetivo, funcionalidades e aprendizados.

## 🎯 Objetivo do repositório
- Praticar lógica de programação do zero até tópicos intermediários/avançados
- Construir um portfólio público mostrando evolução real (do básico ao complexo)
- Aplicar boas práticas desde os primeiros projetos: tratamento de erros, type hints, validação de entradas e organização de código
- Servir de referência futura para revisar conceitos já estudados
## 🧠 Como os projetos estão organizados
Cada pasta segue (ou tende a seguir) o padrão:
- **Descrição do problema**: o que o programa resolve
- **Foco de aprendizado**: quais conceitos de Python o projeto exercita
- **Como executar**: instruções rápidas para rodar o script
- **Aplicação no mundo real**: onde essa lógica aparece em sistemas reais
- **Notas de robustez**: quais edge cases já são tratados
## 🛠️ Requisitos gerais
- Python 3.8 ou superior
- Sem dependências externas na maioria dos projetos (bibliotecas padrão do Python), exceto quando indicado no README específico do projeto
## 🚀 Como rodar um projeto
```bash
cd nome-da-pasta-do-projeto
python nome_do_arquivo.py
```
